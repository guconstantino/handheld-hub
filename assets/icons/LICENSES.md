# Origem dos ícones

- `l-*.svg`: [Lucide](https://lucide.dev) (`lucide-static@1.47.0`), licença ISC.
- `b-*.svg`: [Simple Icons](https://simpleicons.org) (CC0). `b-nintendoswitch.svg` vem da `simple-icons@6.0.0`
  (removido das versões novas). Logos são marcas dos donos; uso pessoal, só como identificação.

Gerar o sprite: `python3 scripts/build_icons.py` → `public/icons.svg`.
